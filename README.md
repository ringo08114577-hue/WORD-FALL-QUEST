# WORD FALL QUEST

英単語バトルを中心にしたアクションRPG。現在はゲームの根幹を順番に実装しています。

## 現在の開発段階

### Step 1 — ゲーム全体の状態管理

- ゲーム状態：タイトル / バトル中 / 一時停止 / 勝利 / 敗北
- プレイヤーHPと敵HPの一元管理
- HPが0になったときの勝敗確定
- 勝利後の次バトル開始
- 状態変更を購読するストア
- 状態の直接変更を防ぐためのfreeze
- Node.js標準テストによる状態遷移テスト

この段階のブラウザ画面は状態管理のテスト用です。落下文字、スペル判定、プレイヤー移動はまだ接続していません。

## 起動方法

ES Modulesを使うため、ローカルサーバー経由で開いてください。

例：

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## テスト

Node.js 18以降を推奨します。

```bash
npm test
```
