# WORD FALL QUEST

英単語バトルを中心にしたアクションRPG。ゲームの根幹システムを独立したモジュールに分け、順番に実装しています。

## 現在の開発段階

### Step 1 — ゲーム全体の状態管理

- ゲーム状態：タイトル / バトル中 / 一時停止 / 勝利 / 敗北
- プレイヤーHPと敵HPの一元管理
- HPが0になったときの勝敗確定
- 勝利後の次バトル開始
- 状態変更を購読するストア
- 状態の直接変更を防ぐためのfreeze
- Node.js標準テストによる状態遷移テスト

### Step 2 — 英単語バトルエンジン

- 日本語のお題と英単語のデータ
- 正しいスペル順の進捗管理
- 最大4種類の文字候補から落下文字を生成
- いま必要な文字が選ばれやすい重み付け
- 5レーンのプレイヤー移動
- 落下位置とプレイヤー位置による取得判定
- 同じ更新タイミングで複数文字が重なっても、取得は1文字だけ
- 正しい文字でスペル進行、間違った文字でミス判定
- 単語完成時の得点ボーナスと次のお題への進行
- STEP 1のHP・敵HPシステムとの接続

### Step 3 — 戦闘処理の整理

- 英単語イベントを戦闘イベントへ変換する専用モジュール
- プレイヤーと敵の攻撃力を分けて管理
- 敵ごとのHP・攻撃力をデータで定義
- 間違った文字を拾うと敵の攻撃力に応じて反撃
- 単語完成時はプレイヤーの攻撃力に応じて敵へダメージ
- 同じイベントIDによる二重ダメージを防止
- HPバーのダメージ表示と勝敗メッセージ
- 戦闘イベントと攻撃力の自動テスト

STEP 2のプレイ画面は `battle.html` です。トップページ `index.html` の「英単語バトルを開く」から移動できます。

## 起動方法

ES Modulesを使うため、ローカルサーバー経由で開いてください。

例：

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## テスト

Node.js 18以降を推奨します。

```bash
npm test
```
