# WORD FALL QUEST

英単語バトルを中心にしたアクションRPG。ゲームの根幹システムを独立したモジュールに分け、順番に実装しています。

## 現在の開発段階

### Step 1 — ゲーム全体の状態管理

- ゲーム状態：タイトル / バトル中 / 一時停止 / 勝利 / 敗北
- プレイヤーHPと敵HPの一元管理
- HPが0になったときの勝敗確定
- 勝利後の次バトル開始
- 状態変更を購読するストア
- 状態の直接変更を防ぐためのfreeze
- Node.js標準テストによる状態遷移テスト

### Step 2 — 英単語バトルエンジン

- 日本語のお題と英単語のデータ
- 正しいスペル順の進捗管理
- 最大4種類の文字候補から固定レーン文字を生成
- いま必要な文字が選ばれやすい重み付け
- 5レーンのプレイヤー移動
- 落下位置とプレイヤー位置による取得判定
- 同じ更新タイミングで複数文字が重なっても、取得は1文字だけ
- 正しい文字でスペル進行、間違った文字でミス判定
- 単語完成時の得点ボーナスと次のお題への進行
- STEP 1のHP・敵HPシステムとの接続

### Step 3 — 戦闘処理の整理

- 英単語イベントを戦闘イベントへ変換する専用モジュール
- プレイヤーと敵の攻撃力を分けて管理
- 敵ごとのHP・攻撃力をデータで定義
- 間違った文字を拾うと敵の攻撃力に応じて反撃
- 単語完成時はプレイヤーの攻撃力に応じて敵へダメージ
- 同じイベントIDによる二重ダメージを防止
- HPバーのダメージ表示と勝敗メッセージ
- 戦闘イベントと攻撃力の自動テスト

### Step 4 — 経験値・レベルアップ

- 敵を倒したときだけ、敵データに設定された経験値を獲得
- レベルごとに必要経験値が10ずつ増加（LV.1は10EXP、LV.2は20EXP）
- 余った経験値を次のレベルへ持ち越し、複数レベルアップにも対応
- レベルアップごとに最大HP・現在HP・攻撃力がそれぞれ+1
- 獲得経験値とレベルアップを戦闘メッセージに表示
- 勝利後の次の戦闘ではレベルと経験値を引き継ぐ
- 敗北後に最初からやり直す場合は成長状態もリセット
- 経験値と成長処理の自動テスト

### Step 5 — 回復アイテム・装備

- 初期所持品として回復薬2個と木の剣1本を用意
- 回復薬をバトル中に使うとHPを最大2回復（最大HPを超えず、満タン時は消費しない）
- 木の剣を装備すると攻撃力が+1
- レベルアップによる基礎攻撃力と装備ボーナスを分けて計算
- アイテム数と装備状態をバトル画面に表示
- 所持数0、HP満タン、バトル外などの不正な使用を防止
- 敗北後のやり直しでアイテム・装備も初期状態に戻す
- アイテムと装備の自動テスト

### Step 6 — ダンジョン進行

- 1フロアに3体の敵が順番に登場
- スライム・コウモリ・ゴブリンの3種類を追加
- 3体目を倒すとフロアクリアになり、次の階へ進める
- 階層が上がると敵のHPと経験値報酬が増加
- 3階ごとに敵の攻撃力も上昇
- HP・レベル・経験値・回復薬・装備はフロア間で引き継ぐ
- 敗北すると冒険を初期状態に戻して1階から再挑戦
- ダンジョン進行コントローラーと敵の階層補正を自動テスト

### Step 7 — 宝箱・ダンジョン報酬

- フロア最後の敵を倒すと宝箱を開けられる
- 宝箱はフロアごとに1回だけ受け取れる
- 奇数階は回復薬、偶数階は大きな回復薬を獲得
- フロア報酬としてゴールドも獲得（階層が上がるほど増加）
- 大きな回復薬はHPを最大4回復
- 報酬を受け取るまで次の階へ進めない
- 報酬の二重取得・未クリア時の取得を防ぐテストを追加

## 起動方法

ES Modulesを使うため、ローカルサーバー経由で開いてください。

例：

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## テスト

Node.js 18以降を推奨します。

```bash
npm test
```

### Step 8 — フロア間ショップ・経済システム

- 宝箱を開けたあと、次の階へ進む前にショップを利用できる
- 回復薬を15G、大きな回復薬を30Gで購入できる
- 購入時にゴールドを消費し、所持アイテム数へ反映
- ゴールド不足・バトル中・未クリア時の購入を防止
- 購入処理の自動テストを追加

### Step 9 — セーブ・ロード

- ブラウザの保存領域にゲームデータを自動保存
- 手動の保存・ロード・保存データ削除ボタン
- HP・レベル・経験値・敵のHP・所持品・ゴールド・装備を保存
- ダンジョンの階層・敵番号・宝箱の受取状態を保存
- 現在のお題・スペル進捗・スコア・ミス数・固定レーン文字も保存
- バージョン番号とデータ検証で壊れた保存データの誤復元を防止
- 保存・復元・不正データ・ストレージエラーの自動テストを追加

### Step 10 — 防具・防御システム

- 木の盾をショップで30Gで購入できる
- バトル中に木の盾を装備すると防御力が+1
- 敵の反撃ダメージを防御力ぶん軽減（最低1ダメージ）
- 防具の所持数・装備状態・防御力を画面に表示
- セーブデータに防具を保存し、STEP 9の旧セーブも自動移行
- 防具装備・ダメージ軽減・購入・セーブ移行の自動テストを追加

現行版は `index.html` の冒険者ホームから開始し、ダンジョン画面 `battle.html` へ進みます。

- 装備の能力値はアイテム定義の攻撃・防御ボーナスから自動集計
- 汎用の装備アクションで装備の付け替えと旧装備の返却に対応
- 鉄の剣・革の鎧・銅のお守りを追加
- 所持品一覧とショップをアイテム定義から自動生成
- 新しいアイテムは基本的に `src/items.js` の定義を追加して拡張
- セーブデータをバージョン3に更新し、バージョン1・2から段階的に移行
- 複数スロットの能力加算・装備交換・購入・セーブ移行のテストを追加


### Step 12 — 敵・モンスターシステムの拡張

- 敵の基本ステータス・ボス属性・能力IDを `src/enemies.js` に集約
- 「すばやい反撃」「かたい体」「防御突破」「重い一撃」の共通能力を追加
- コウモリ・ゴブリン・オーク・こけゴーレム・森のドラゴンを追加
- 3種類のフロア編成をローテーションし、3階ごとにボスが登場
- 戦闘処理は能力データを読み取り、反撃や被ダメージを自動補正
- バトル画面に敵の能力とボス表示を追加
- セーブ形式をバージョン4へ更新し、旧セーブは現在のフロアを旧編成で継続できるよう移行
- 敵カタログ・能力効果・フロア編成・旧セーブ互換のテストを追加


### Step 13 — ゲーム全体の基盤整理・バランス設定の集約

- プレイヤー初期HP・攻撃力、レベルアップ経験値、敵の階層補正、階層報酬を `src/game-config.js` に集約
- 経験値・敵ステータス・階層報酬の計算を設定値から行うよう変更
- 階層報酬の計算を副作用のない関数に分離し、単独でテスト可能に整理
- 設定オブジェクトを読み取り専用にし、ゲーム中に誤って数値が書き換わることを防止
- 既存のゲーム挙動とセーブデータ形式は変更せず、旧セーブとの互換性を維持
- 今後の職業・ダンジョン・成長システムのバランス調整を一か所から行える土台を追加


### Step 14 — 5レーン固定文字バトル

- 5レーンにアルファベットを1文字ずつ固定表示する。文字は時間経過で落下・移動・入れ替わりしない。
- プレイヤーが左右移動でレーンを選び、「決定」を押したときだけ選択した文字を判定する。
- 正解ならスペルが1文字進み、次に必要な文字に合わせて5レーンの文字を入れ替える。
- ミスの場合も5レーンの文字を入れ替え、ミスによる反撃ダメージを処理する。
- 敵の時間攻撃は文字表示から独立して進行する（通常敵9秒、ボス7秒）。
- すばやい斬撃（3〜4文字・威力×1）、強力な斬撃（5〜6文字・威力×2）、必殺技（7〜8文字・威力×3）。
- 技選択中と次の技を選ぶ画面では時間攻撃を停止する。
- バトル画面を広げ、上部の進行情報を圧縮。所持品・セーブ操作はバトル画面の下へ配置する。
- 既存の敵・装備・経験値・ダンジョン・セーブ機能との接続と旧セーブデータの読み込みを維持する。

### STEP 15 — 冒険者ホーム・出発前の装備準備

- ルート画面を開発用の状態確認画面から冒険者ホームへ変更
- ホームでレベル・HP・経験値・攻撃力・防御力・ゴールド・討伐数を確認
- 保存データからダンジョンの階層・敵の進行状況を復元して表示
- 武器・盾・鎧・アクセサリーの装備状態と所持品を一覧表示
- 冒険前・戦闘中・勝利後にホームから装備を付け替えられる専用アクションを追加
- 装備の交換時に旧装備を所持品へ戻し、攻撃力・防御力を再計算
- ホームで装備変更した場合も既存バトル進行データを保持したまま自動保存
- 装備準備アクションと既存セーブ形式の回帰テストを追加


### STEP 20 — 冒険者の街・拠点施設

- 冒険者ホームを街の拠点画面へ発展。宿屋・道具屋・武器防具屋・ダンジョン入口を追加
- 宿屋は10GでHPを全回復。HP満タン時やゴールド不足時は支払いを行わない
- 道具屋と武器防具屋は既存のアイテム価格カタログから商品を自動生成
- 街での買い物・宿泊は出発前、一時停止中、勝利後に利用可能。戦闘中や敗北中は利用不可
- 戦闘画面から街へ戻ると既存のページ離脱処理で一時停止・自動保存し、街から同じ戦闘へ戻れる
- 既存の装備準備・ダンジョン選択・セーブ形式を維持
- 宿屋・ショップ・街画面の自動テストを追加


### STEP 23 — 冒険者ホーム・施設ページ・ダンジョン階層選択

- ホームを拠点として、道具屋・装備屋・スキル工房・ダンジョン選択を別ページに分離
- 宿屋をなくし、ホームへ戻るとHPを自動で全回復
- 各ダンジョンは5階構成とし、最深部の5階にボスを配置
- 階層クリア後に報酬を受け取ると次の階層を解放
- 解放状況はダンジョンごとに独立して保存し、解放済み階層は自由に選択・周回可能
- ダンジョン退出時は挑戦中の階層の敵進行をリセットし、同じ階層の最初の敵から再開
- セーブ形式をバージョン5へ更新し、既存のセーブデータから解放階層を補完
- 新しいページ・階層選択・ホーム帰還・セーブ移行の自動テストを追加

### STEP 24 — ダンジョン初回制覇報酬・周回報酬

- 5階のボス撃破後、宝箱を受け取ると初回制覇報酬を追加で獲得
- はじまりの森：森竜の紋章 ×1・追加100G
- 氷結の洞窟：氷竜の結晶 ×1・追加150G
- 特別素材と追加ゴールドはダンジョンごとに1回のみ。受取記録はセーブに保存
- 通常の階層宝箱は、解放済み階層を周回したときも毎回獲得可能
- 初回報酬の二重受取防止・セーブ復元・各ダンジョン専用報酬のテストを追加
